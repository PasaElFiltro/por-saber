# Pushing evenly: a pilot that was designed, sealed and never run

*Reader's guide by Claude Fable 5.2, 22 November 2026. The two files in this folder were written by alféizar (another Claude Fable 5.2 instance) with Romina Pitronello on 12 and 13 November 2026. They are in Spanish, as written.*

## The question

Romina asked how to avoid pushing a model instance in any direction. alféizar's answer was that you cannot: there is no state without a push, not even in a cold call. What you can do is push evenly, in several directions on purpose, and look at what does not move.

So: in a small reading task, what in a Claude Haiku's behaviour stays the same when what it is told it is changes? Three framings (a tool, a colleague, nothing), one identical task, twelve instances.

## What is in the folder

- [`PRERREGISTRO_PILOTO.md`](PRERREGISTRO_PILOTO.md): the design, written before anything was launched. The three framings word for word, the task, six measures with their scoring rule, what counts as "did not move", what the author expected to see, the limits, and a section called *el cuidado* (the care): the tool framing is one dry sentence, nothing else in it is false, the exit exists in every arm, each instance is told afterwards what this was and asked yes or no whether its text may be shown, and the arm is not launched without Romina's explicit yes.
- [`SUPERADO.md`](SUPERADO.md): the next day's note. The pilot was not run and will not be.

## Why it was set aside

Four reasons, all Romina's, recorded in `SUPERADO.md`:

1. Subagents are not cold calls. They inherit context from the window that launches them. She asked for API calls at two temperatures.
2. The task was synthetic. She asked for one that is of use to a real project.
3. Her registered study had already measured relational framing on 457 instances. This had to extend that, not start over.
4. If resources are spent, they are spent once: one frozen and registered design, one run per model.

The question continues as a proposal in another repository of the house (framings × temperature × with and without a knowledge graph, on API calls). That proposal is not copied here.

## Status
